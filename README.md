# Horn of the Abyss Patches

Unofficial, version-locked patches for Heroes of Might and Magic III:
Horn of the Abyss.

## Patches

- [Nyx Pixie Elementalist](inteus-pixie-elementalist/README.md), version
  1.2.1, for HotA 1.8.0
- [Nyx Spiritism](nyx-spiritism/README.md), version 0.1.0, for the installed
  HotA 1.8.0 Nyx patch

The repository contains patching code, documentation, and the user-supplied
Nyx portrait. It does not contain Heroes III or Horn of the Abyss executables,
archives, or extracted game assets.

These patches are not affiliated with or supported by the Horn of the Abyss
team. Use a separate game installation and keep automatic updates disabled.
